# Automotive Reels — ZEEKR 9X Hyper

Тест оформления и исходный проект Remotion. Тест: 5,9 секунды исходного видео (13,8–19,7 с). Полный рендер ожидает утверждения оформления.

Название модели подтверждено пользователем. Характеристики взяты из его SRT. Таймкоды коротких фраз предварительные: исходный SRT содержит четыре крупные реплики, без пословного выравнивания.

Файлы проекта и тестовый MP4 добавляются в этот репозиторий.
