# ZEEKR 9X Hyper — тест оформления Reels

## Версия 2 — Montserrat Black 900

- [Скачать новый тестовый MP4, 1080×1920, 5,9 с](./style-test-v2.mp4?raw=true)
- [Скачать обновлённый проект Remotion с медиа](./automotive-reels-project-v2.zip?raw=true)

На Mac откройте скачанный MP4 в QuickTime. Новая версия использует Montserrat Black 900: каскадные входы текста через маски, раздельную прокрутку цифр с пружинным торможением, прорисовку шкалы и последовательные входы технических подписей. Оригинальная речь сохранена.

Код доступен в папке `project/`; все необходимые медиа находятся в ZIP. Распакуйте ZIP, откройте папку `automotive-reels` в Терминале, выполните `npm ci`, затем `npm run dev -- --no-open`.

Тест: исходный диапазон 13,8–19,7 с. Полный рендер ожидает утверждения оформления. Название модели подтверждено пользователем. Характеристики взяты из пользовательского SRT. Таймкоды коротких фраз предварительные: SRT содержит крупные реплики без пословного выравнивания. Каскад слов — анимация появления фразы, а не измеренная синхронизация отдельных слов. В ZIP видеоряд дополнительно сжат для передачи, оригинальное AAC-аудио скопировано без перекодирования.
