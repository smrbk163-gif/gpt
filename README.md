# ZEEKR 9X Hyper — тест оформления Reels

## Версия 3 — лайм, белый, свет и звук

- [Скачать новый тестовый MP4, 1080×1920, 5,9 с](./style-test-v3.mp4?raw=true)
- [Скачать обновлённый проект Remotion с медиа](./automotive-reels-project-v3.zip?raw=true)

На Mac откройте MP4 в QuickTime. Montserrat Black 900, курсив для цифр и субтитров. По референсу пользователя: лаймовый #BFFF00, белый #FFFFFF и зелёный градиент цифр. Тени букв удалены: за текстом плавно появляется локальное мягкое затемнение, затем выезжает текст и графика. Блоки центрированы по горизонтали в свободных зонах кадра.

Три самостоятельных графических мотива: импульс мощности, три моторных символа и кривая ускорения. Каждому соответствует авторский стереоэффект: whoosh с низким ударом, три электрических щелчка и нарастающий свип. Оригинальная речь сохранена. Плавное приближение и отдаление камеры — до 3,8%.

Код находится в `project/`; все медиа — в ZIP. Распакуйте ZIP, откройте `automotive-reels` в Терминале, выполните `npm ci`, затем `npm run dev -- --no-open`. `scripts/generate_sfx.py` воспроизводит звуковые эффекты с seed 3303. Цвета, затемнение, камера, громкость и таймкоды меняются в `src/config.ts`.

Тестовый диапазон исходника 13,8–19,7 с. Полный рендер ожидает утверждения стиля. Название модели подтверждено пользователем; характеристики — из его SRT. Таймкоды коротких фраз предварительные: исходный SRT не содержит пословного выравнивания. В ZIP видеоряд дополнительно сжат для передачи, оригинальное AAC-аудио скопировано без перекодирования.
