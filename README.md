# ZEEKR 9X Hyper — тест оформления Reels

## Скачать и посмотреть

- [Тестовый MP4, 1080×1920, 5,9 с](./style-test-1080p.mp4?raw=true)
- [Компактный MP4, 720×1280](./style-test.mp4?raw=true)
- [ZIP проекта Remotion с видеорядом, звуком и субтитрами](./automotive-reels-project.zip?raw=true)

На Mac скачайте MP4 и откройте его в QuickTime Player. Код также доступен в папке `project/`; все необходимые медиа находятся в ZIP. Распакуйте ZIP, откройте папку `automotive-reels` в Терминале, выполните `npm ci`, затем `npm run dev -- --no-open`. Используйте локальный адрес, который напечатает команда.

Тест: исходный диапазон 13,8–19,7 с. Сохранена оригинальная речь, добавлены авторские мягкие звуковые акценты. Полный рендер ожидает утверждения оформления.

Название модели подтверждено пользователем. Характеристики — из пользовательского SRT. Таймкоды коротких фраз предварительные: SRT содержит четыре крупные реплики, без пословного выравнивания. В ZIP видеоряд сжат дополнительно для передачи; аудио AAC сохранено без изменения. Тестовый 1080p MP4 — исходный проверенный рендер.
