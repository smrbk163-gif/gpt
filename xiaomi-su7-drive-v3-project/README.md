# Xiaomi SU7 Drive V3

Softer area downscale replaces Lanczos to reduce fine-detail ringing/aliasing. Existing source compression and capture blur cannot be reconstructed.

Subtle neutral-white grade with slightly cool shadows, gentle tonal shaping and 2.5% saturation increase. CRF16 master. Previous rolling counters, diagrams and stronger synchronized SFX retained. No narration. User specifications and CLTC qualifiers retained.
