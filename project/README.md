# Automotive Reels — полный ролик

Remotion 4.0.534 · React · TypeScript. Исходник: 720×1280, 59,94 fps, 19,7197 с. Композиции: 1080×1920, 30 fps.

## Просмотр и экспорт

```sh
npm ci
npm run dev -- --no-open
```

`StyleTest` — 5,9 с, исходный диапазон 13,8–19,7 с. `AutomotiveReel` — полная композиция, стиль утверждён пользователем, полный MP4 экспортирован.

```sh
npx remotion render src/index.ts StyleTest style-test.mp4 --codec=h264 --crf=21 --audio-codec=aac
```

## Оформление

Montserrat Black 900, курсив в цифрах и субтитрах. Лаймовый #BFFF00 и чистый белый #FFFFFF по пользовательскому референсу; цифры — с градиентом #D9FF00 / #BFFF00 / #79D700. Тени букв отсутствуют. Локальное мягкое затемнение появляется до текста и уходит вместе с ним. Характеристики и субтитры центрированы по горизонтали в свободных зонах над лицом и ниже корпуса.

Цифры прокручиваются в отдельных разрядах и раскрываются через маску; под ними три разных технических мотива: импульс мощности, три моторных символа и кривая ускорения. Каскад слов — анимация входа целой фразы, не измеренная пословная синхронизация. Камера плавно приближается до 3,8% и отдаляется, с возвратом на исходных склейках. Лицо и важные детали остаются в кадре.

## Звук

Оригинальная AAC-речь скопирована без перекодирования. Для каждой графики синтезирован свой оригинальный стереоэффект: whoosh с низким ударом для мощности, три электрических щелчка в моменты входа моторных символов, нарастающий свип с коротким ударом для кривой ускорения. Сторонней музыки нет. Эффекты воспроизводимы: `python scripts/generate_sfx.py`, фиксированный seed 3303. Таймкоды — в `sfx-timing.json`.

## Настройки и данные

- `src/config.ts`: цвета, размеры, расположение, анимация, степень затемнения, зум, громкость эффектов, характеристики и таймкоды.
- `src/phrases.json`: короткие блоки субтитров и смысловые акценты.
- `src/captions.json`: исходные реплики пользователя в формате Remotion Caption.
- `public/source.srt`: неизменённый пользовательский SRT.
- `analysis.json`: параметры, склейки и статус точности тайминга.
- `src/Automotive.tsx`: видео, камера, затемнение, субтитры, инфографика, звук.

Название ZEEKR 9X Hyper подтверждено пользователем. Значения 1401 л.с., 3 электромотора и 3,1 с взяты из его SRT, внешняя проверка характеристик не проводилась. SRT содержит четыре крупные реплики; границы коротких подфраз предварительные. Перед полным экспортом требуется проверка синхронизации по речи.

В ZIP видеоряд дополнительно сжат H.264 для передачи. Шрифт Montserrat — OFL, пакет @fontsource/montserrat входит в зависимости. Исходное разрешение 720p; экспорт 1080p не восстанавливает отсутствующие детали исходника.

## Финальный экспорт

```sh
npx remotion render src/index.ts AutomotiveReel zeekr-9x-reel.mp4 --codec=h264 --video-bitrate=4M --audio-codec=aac --audio-bitrate=192k
```

Все исходные планы сохранены. Звук входа названия модели добавлен к утверждённым эффектам характеристик. Экспорт 1080×1920, 30 fps, H.264 / AAC, 592 кадра (исходные 19,7197 с округлены вверх до сетки 30 fps).
