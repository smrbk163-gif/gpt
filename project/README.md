# Automotive Reels — тест оформления

Remotion 4.0.534 · React · TypeScript. Исходник пользователя: 720×1280, 59,94 fps, 19,7197 с. Композиции: 1080×1920, 30 fps. Вертикальный кадр сохранён целиком, без кропа. H.264-версия исходника нужна для надёжного воспроизведения в браузере; AAC-речь скопирована отдельно без перекодирования.

## Запуск

```sh
npm ci
npm run dev -- --no-open
```

В Studio доступны `StyleTest` (5,9 с, исходный диапазон 13,8–19,7 с) и `AutomotiveReel` (полная композиция, пока без утверждения). Полный MP4 не экспортирован: по ТЗ сначала нужно утвердить тест.

```sh
npx remotion render src/index.ts StyleTest style-test.mp4 --codec=h264 --crf=18 --audio-codec=aac
```

## Настройки

- `src/config.ts`: цвет, шрифт, размер и положение субтитров, анимация, интенсивность коррекции, громкость акцентов, характеристики и таймкоды.
- `src/phrases.json`: короткие блоки субтитров и смысловая подсветка.
- `src/captions.json`: исходные реплики в формате Remotion Caption.
- `public/source.srt`: неизменённый SRT пользователя.
- `analysis.json`: параметры исходника, склейки, размещение графики и статус точности тайминга.
- `src/Automotive.tsx`: все компоненты графики, речи и видео.

## Точность текста и тайминга

Название `ZEEKR 9X Hyper` подтверждено пользователем. Значения 1401 л.с., 3 электромотора и 3,1 с взяты из пользовательского SRT; внешняя проверка характеристик не проводилась.

SRT содержит четыре крупные реплики, а не таймкоды слов. Начала и концы исходных реплик сохранены в captions.json. Внутреннее дробление на короткие блоки и моменты появления характеристик предварительные: не выдаются за измеренную пословную синхронизацию. Подсвечиваются смысловые фрагменты, а не каждое произнесённое слово. Перед полным экспортом требуется проверить синхронизацию по тесту и, при необходимости, уточнить тайминг.

Оригинальная речь сохранена. Звуковые акценты синтезированы специально для проекта с фиксированным seed 33, сторонняя музыка не используется. Шрифт Montserrat распространяется по OFL; пакет @fontsource/montserrat включён в зависимости.

## План оформления

Первый план: спокойная кинетическая типографика; название модели над автомобилем в свободной зоне. Второй план: короткие блоки реплики без крупных характеристик. Третий план: одна характеристика за раз в верхней левой зоне стены, субтитры на свободной нижней части кадра. Лицо ведущего остаётся открытым. Контраст и насыщенность изменены умеренно; цвет автомобиля сохранён.

## Версия 2

Montserrat Black 900. Каскадные входы слов через маски, прокрутка разрядов цифр с пружинным торможением, прорисовка акцентной шкалы, раздельные входы заголовка и единиц измерения. Входы слов — дизайн появления фразы, не пословные таймкоды речи.
