# Xiaomi SU7 — От первого лица

1080×1920, 60 fps, 57,4 секунды. Исходный голос в обычном темпе. Порядок: source-2 (обход снаружи), затем source-1 (салон и задняя часть).

Субтитры по одному слову. Пользовательские SRT сверены с двумя независимыми распознаваниями; исправлены ошибки в названии модели, регистрации и мощности. captions-source JSON сохраняет время относительно исходного видео. Условие startMs <= t < endMs исключает наложение слов.

HUD: Montserrat Black 900, белый и #BFFF00, постоянный плавный нижний градиент без теней букв, анимация чисел, линий и карточек. Линии декоративные, не автоматическое распознавание. Характеристики из предоставленного объявления; CLTC подписан. Слова об отсутствии ДТП не представлены как результат диагностики.

Звук: голос highpass 65Hz, loudnorm, лимитер; синтезированные swish/chime/tick на карточках, приглушённые под речь. Звука на каждом слове нет. Новая музыка не добавлена.

Изображение: мягкая стабилизация перемещения до 8px без вращения, кроп 2,4%, bilinear без искусственной резкости или генерации промежуточных кадров, умеренная коррекция яркости и насыщенности. Сжатые оригиналы ограничивают детализацию.

## Сборка

Оригиналы: E821 — source 1, F9B — source 2; пути inputs.json. Python: numpy, scipy, Pillow. FFmpeg: libvidstab, libx264.

python scripts/detect.py
python scripts/render.py
python scripts/audio.py

Склейка concat.txt с public/soundtrack.m4a через ffmpeg -c copy; цветовые метаданные H264 primaries=1,transfer=1,matrix=6,limited range. Remotion Studio: npm install && npx remotion studio. Две отдельные видеодорожки; визуальные слои предварительно скомпонованы scripts/render.py.


## V2: правки обратной связи

Все символы в анимированной числовой строке выровнены по общей типографской базовой линии, включая точки, запятые и единицы. Панорама: начало 6,6 с второго фрагмента (в глобальном таймлайне 35,22 с), синхронно с произнесённым словом. Указатели и scan-маркеры плавно убираются через 1,05 с после появления карточки. Фон субтитров заменён постоянным нижним градиентом во всю ширину: начало 1100 px с нулевой производной, максимальная непрозрачность 140/255 у низа. Звук появления панорамы перенесён вместе с карточкой.
