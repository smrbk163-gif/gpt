# Xiaomi SU7 Drive V2 — quality master, interior, kinetic infographics

36.4 seconds, 1080×1920 at 60 fps, original supplied MAMA MA instrumental track excerpt starting 4.55s. Narration omitted per user choice. Selected interior shots added: panorama/seats, steering, instrument panel, central screen and comfort/console.

Master quality: H.264 CRF16 variable bitrate, no small-file bitrate cap. Source decoded once for stabilization/remapping and frame graphics, directly encoded as the final prepared scenes. Original compressed 4K sources scaled with Lanczos. Existing compression/detail loss in source is not reconstructable. No frame blending; native-rate samples at 60fps. No aggressive ending zoom punches. Original movements preserved while fine shake is reduced.

Two-pass vidstab: detect at output resolution, smoothing=22, maxshift=18px, maxangle=0.008rad, fixed 4.5% safety zoom. Visually check crop/edges. Speed ramps are milder (0.20/0.25 sinusoidal time remapping), minimizing slow-rate duplication.

Montserrrat Black 900, white and #BFFF00. Rolling digit columns stagger and settle in ~0.7s. Different animated illustrations: power waveform/equalizer, acceleration curve, rear-drive diagram, mirror fold/frame, sequential LED beams, panorama grid, steering outline, display diagonal, seat heat/vent flow, sequential battery cells, traced range route, circular charge dial, maximum-speed gauge and listing pin. No duplicate subtitle layer. CLTC qualifier and 99,000km mileage retained.

Original stereo swishes, seven reel ticks, settle hits/chimes and eight battery-cell clicks. Short music dips under animation SFX. Timing documented in sfx-timing.json. No voice clone/reference published.

Each prepared scene is independently authored in Remotion. npm ci && npm run dev; composition SU7DriveV2. Scripts render.py and sound.py reproduce preprocessing using original uploads and local inputs.json paths. Final master is stream-copied from the same high-quality prepared scenes and mixed AAC audio. This text-source folder excludes media; high-quality master is delivered separately.
