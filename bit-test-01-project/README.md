# Bit — first trial

Four original DJI angles, ~7.983 seconds, 1080×1920, 60fps. No review-style subtitles. Music: supplied LET ME DRIVE FUNK slowed, excerpt starting at 4.514s. Cuts at 2, 4, 6s aligned to strong accents in the excerpt. Smooth continuous sinusoidal time remapping, fast approach/exit with a slower center, subtle center zoom and 55ms horizontal blur at transitions. Frame blending smooths slow sections; this is not optical-flow reconstruction. Three original short stereo swishes and low arrival taps mixed under music. Original ambient audio muted.

Remotion editable preview: npm ci && npm run dev. Composition BeatEdit. Media in public/. Preprocessed ramps are independent clip nodes; script scripts/prepare.py regenerates them from original source files. Final video exported with FFmpeg from the same four prepared clips and mixed audio used by the Remotion preview.

This is a compact trial using all four supplied short shots. Their camera motion is subtle, so ramp strength remains restrained.
